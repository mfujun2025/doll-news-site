# 充气娃娃.cn — 成人用品行业资讯网站原型

聚焦成人情趣用品领域的垂直资讯门户原型，以科学、理性、合规的视角服务成年用户。

## 页面

- `index.html` — 首页（行业资讯、产品科普、选购指南、两性健康、法律法规）
- `manufacturers.html` — 生产厂家导航（支持搜索、地区筛选、品类筛选）

## 功能特性

- 18+ 年龄确认弹窗
- 响应式布局，适配桌面与移动端
- ECharts 市场规模数据可视化
- 厂家卡片筛选与搜索
- 浅红浅色主题

## 合规声明

本站内容仅限年满 18 周岁的成年人访问，不发布、不传播任何淫秽色情内容。产品相关图片均经过艺术化处理。本站内容仅供参考，不构成医疗建议。
